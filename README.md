# editmatker — AI Edit Studio

인물과 분위기를 입력해 최신 공개 영상 후보를 찾고, 사용 권한을 확인한 업로드 영상으로 AI 편집 타임라인과 세로형 MP4 초안을 만드는 한국어 편집 작업대입니다.

## 시작하기

```bash
pnpm install
pnpm dev
```

Node.js 22+, pnpm 10.18+, `ffmpeg`, `ffprobe`, 그리고 한글 자막용 Noto CJK 글꼴이 필요합니다. 컨테이너 배포는 Dockerfile에서 FFmpeg와 글꼴을 설치합니다. `pnpm check`, `pnpm test`, `pnpm build`로 타입·테스트·프로덕션 빌드를 실행합니다.

검색 및 AI 초안에는 실행 플랫폼에서 제공하는 `MANUS_API_URL`과 `MANUS_API_KEY` 서버 환경변수가 필요합니다. 로컬 사용 시 이를 비밀 저장소나 로컬 환경에 설정하고 `.env`를 Git에 커밋하지 마세요. 변수가 없으면 검색·AI 기능은 오류를 안내하고 비밀 키는 브라우저로 전송하지 않습니다.

## 편집 흐름

1. 인물과 분위기를 입력해 YouTube의 최신 공개 영상 후보를 검색합니다. 제목, 채널, 게시 시점, 썸네일과 원본 링크를 보여주며, 검색 결과는 참고 자료일 뿐 자동으로 내려받거나 편집 소스로 쓰지 않습니다.
2. 직접 제작했거나 편집·재사용 권한을 받은 클립 및 선택적 배경음악을 업로드하고 권리 확인에 동의합니다. MP4/MOV/M4V/WebM 영상과 MP3/M4A/WAV/AAC 오디오를 지원하며 각 파일은 최대 80MB입니다.
3. AI가 업로드 영상의 길이를 고려한 장면 순서, 컷 길이, 한국어 캡션과 컷/페이드 전환의 편집 타임라인을 제안합니다.
4. FFmpeg가 9:16, 540×960 MP4 미리보기를 생성합니다. 업로드한 배경음악이 있으면 짧게 믹스해 영상에 포함합니다. 파일과 타임라인 JSON을 각각 저장할 수 있습니다. 자동 게시 기능은 없습니다.

## 데이터와 권리

- 검색 결과의 권리 상태는 확인되지 않으며 사용자 확인 없이 편집에 들어가지 않습니다. 업로드 전 확인란은 사용자의 자기확인(honor system)이며 저작권 소유권을 검증하거나 법적 허가를 판정하지 않습니다.
- 각 임시 미디어 작업에는 서버 발급 무작위 세션 토큰을 사용합니다. 업로드·편집·렌더는 그 토큰에 묶여 다른 세션의 자산 ID만으로 접근할 수 없으며 토큰은 브라우저 `sessionStorage`에 보관됩니다. 이 익명 세션은 계정 로그인·기기 간 접근·영구 사용자 인증을 대신하지 않습니다.
- 업로드 미디어는 서버의 임시 작업 디렉터리에만 보관되며 최대 2시간 후 정리됩니다. 서버 재시작·컨테이너 교체 시 더 일찍 사라질 수 있고 프로젝트 파일로 Git에 저장하지 않습니다.
- 공개 API는 서버 프로세스의 IP별 고정 창 요청 제한(검색/AI tRPC 30회/분, 업로드 12회/10분, 렌더 8회/10분)을 사용합니다. 이는 단일 프로세스 수준의 기본 완화책이지 분산 환경의 완전한 남용 방지 보장은 아닙니다.
- 최근 프로젝트와 타임라인 메타데이터는 브라우저 `localStorage`에 저장합니다. 원본 파일, MP4 렌더 결과, 계정 간 동기화는 저장하지 않으므로 원본이 만료된 뒤에는 영상을 다시 업로드해 타임라인을 재구성해야 합니다.
- LLM 및 API 허브 키는 서버 환경 변수 `MANUS_API_URL`, `MANUS_API_KEY`만 사용합니다. 브라우저 번들에 비밀 키를 넣지 않습니다. 내보낸 MP4는 사용자 기기에 다운로드됩니다.
- 영상 수집 API는 YouTube 검색만 연동되어 있습니다. 일반 웹 기사 검색 또는 다른 플랫폼 검색을 지원한다고 가정하지 않습니다.

## 구현 구성

- `client/src/pages/Home.tsx`, `client/src/index.css`: 편집 워크스페이스 UI와 브라우저 프로젝트 목록.
- `server/editmaker.ts`: API 허브 검색 결과 정규화, LLM 타임라인 생성, 임시 파일 업로드, FFmpeg 렌더.
- `server/routers.ts`: 입력 검증된 검색/AI tRPC 절차.
- `server/_core/index.ts`: 미디어 HTTP 엔드포인트 등록.
- `client/public/manus-routes.json`: 단일 공개 페이지 경로 선언.

앱은 React, Express, tRPC, TypeScript 및 Drizzle 스타터를 기반으로 하며 DB는 현재 사용하지 않습니다.
